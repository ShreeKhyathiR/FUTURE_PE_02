# 🎬 AI UGC Ad Generator

An AI-powered web application that generates authentic User Generated Content (UGC) ad scripts for businesses using Prompt Engineering and AI.

This project was developed as part of the AI Content Marketing Internship.

---

## 🚀 Features

- Generate authentic UGC-style ad scripts
- 5 Viral Hooks
- 3 UGC Ad Scripts
- 5 Strong Call-to-Actions (CTAs)
- Social Media Caption
- Download generated content as a text file
- Easy-to-use web interface
- Prompt-based AI content generation

---

## 🛠 Technologies Used

- Python
- Streamlit
- OpenRouter API
- Prompt Engineering
- HTML & CSS

## ⚙️ Installation

1. Clone this repository

2. Install the dependencies

```
pip install -r requirements.txt
```

3. Add your API key inside a `.env` file

```
OPENROUTER_API_KEY=your_api_key_here
```

4. Run the application

```
streamlit run app.py
```
